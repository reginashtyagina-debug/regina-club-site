# Деловой клуб Регины Штягиной

Статический лендинг клуба: заявка на вступление. Без сборки, открывается как есть (подходит для GitHub Pages).

- `index.html` — главная страница
- `privacy.html` — политика обработки персональных данных
- `styles.css`, `script.js` — стили и отправка формы
- Места, где нужен реальный текст, отмечены в вёрстке классом `tbd` и квадратными скобками.

Чтобы форма начала принимать заявки, укажите `FORM_ENDPOINT` или `CLUB_EMAIL` в начале `script.js`.
