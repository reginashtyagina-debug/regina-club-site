# Деловой клуб Регины Штягиной

Одностраничный лендинг клуба. Он ведёт на оплату тест-драйва или года в GetCourse.

Сайт сделан на чистом HTML, CSS и JavaScript без сборки: страница одна, а без фреймворка она быстрее загружается с телефона, и её можно править прямо в файлах. Подходит для GitHub Pages и любого статического хостинга.

Дизайн-план и принятые решения описаны в `DESIGN.md`.

## Где что лежит

| Файл | Что в нём |
|---|---|
| `js/config.js` | Цены, сроки, ссылки GetCourse, подзаголовок, вопросы и ответы, видео, фото, счётчик Метрики |
| `data/schedule.json` | Расписание встреч |
| `data/speakers.json` | Спикеры |
| `data/story.json` | История «Путь от участника к эксперту» |
| `data/reviews.json` | Скриншоты отзывов |
| `index.html` | Тексты блоков |
| `css/styles.css` | Оформление |
| `privacy.html` | Политика обработки персональных данных |

## Режим просмотра

Откройте страницу с `?demo=1` в адресе, например `https://адрес-сайта/?demo=1`. В этом режиме:

- данные берутся из `data/demo/`, поэтому видны все блоки, даже пока реальных данных нет;
- вопросы с пометкой `[ЗАПОЛНИТЬ …]` показываются с подсветкой;
- события Метрики не отправляются, а печатаются в консоль браузера.

Без `?demo=1` блоки без данных и вопросы без ответа скрыты.

## Как заменить

### Ссылки GetCourse и цены

В `js/config.js`:

```js
trial: { price: 5490,  days: 30,  url: "https://….getcourse.ru/…" },
year:  { price: 54900, months: 12, url: "https://….getcourse.ru/…" },
creditedYearPrice: 49410,
creditWindowDaysAfterTrial: 7,
```

Цены, сроки и условие зачёта выводятся на странице везде автоматически. Пока ссылка не начинается с `https://`, кнопки ведут к блоку условий.

Метки `utm_*` и параметр `from` из адреса страницы добавляются ко всем ссылкам GetCourse без изменений.

### Акцент пакета

- Обычный переход: главная кнопка «Начать тест-драйв», выделена карточка тест-драйва.
- Тёплый трафик: при `?from=event`, `?from=ufa`, `?from=year` главная кнопка «Вступить на год», выделена карточка года.

Список значений задаётся в `warmFrom`. Если меняете его, поправьте и короткий скрипт в `<head>` файла `index.html`: он ставит акцент до отрисовки, чтобы первый экран не перескакивал. Части адресов страниц программы, с которых приходит тёплый трафик, перечислите в `warmReferrers`.

### Расписание

`data/schedule.json`, время с часовым поясом:

```json
[
  { "date": "2026-11-05T19:00:00+03:00", "type": "meeting", "topic": "Тема встречи", "expert": "Имя эксперта" },
  { "date": "2026-11-12T19:00:00+03:00", "type": "state", "topic": "Тема эфира", "expert": "Регина Штягина" }
]
```

`type`: `meeting` — встреча с экспертом, `state` — эфир «Состояние». На странице показываются 4 ближайшие встречи и ближайший эфир. Прошедшие события скрываются сами. Если ближайших событий нет, блок не показывается.

### Партнёры и спикеры

`data/speakers.json`, каждая карточка:

```json
{ "group": "featured", "name": "Имя Фамилия", "topic": "Регалия одной строкой", "photo": "assets/img/people/фамилия.webp", "url": "" }
```

- `group: "featured"` — 12 главных карточек, видны сразу. Порядок в файле — порядок на сайте.
- `group: "more"` — остальные эксперты клуба, открываются по кнопке «Ещё эксперты и партнёры».
- `kind: "rubric"` — ведущие рубрик чата, список под сеткой.

Строка под сеткой задаётся в `js/config.js`, поле `expertsNote`. Числа в ней нет: состав клуба постоянно пополняется. Карточки с именем в квадратных скобках, например «[Имя] Горина», не показываются, пока имя не заполнено. Фото квадратное, от 300×300 px, WebP; на сайте оно круглое.

### История участницы

`data/story.json`:

```json
{ "name": "Имя", "result": "Результат одной фразой", "topic": "Тема её эфира в клубе", "photo": "assets/img/story.webp" }
```

Пока в файле `null`, блок скрыт.

### Отзывы

`data/reviews.json`. Отзыв набирается текстом в фирменную карточку:

```json
{ "name": "Имя Фамилия", "role": "Брендмейкер", "source": "Комментарий из социальных сетей", "text": "Текст отзыва" }
```

`role` и `source` необязательны; без `source` под карточкой стоит «Из закрытого чата клуба». Текст переносится как есть, без смайлов; исправляются только опечатки и знаки препинания, сокращения — без изменения смысла.

Можно поставить и скриншот: `{ "src": "assets/img/reviews/01.webp", "alt": "Краткая суть сообщения" }`.

### Видео с мероприятия в первом экране

`eventVideo` в `js/config.js`: `assets/video/event.mp4` и `event.webm` (540×960, без звука, около 0,7 МБ), обложка `assets/img/event-poster.webp`. Видео идёт по кругу без звука, с кнопкой паузы, только пока первый экран на виду. При «уменьшении движения» и экономии трафика показывается только обложка. Чтобы заменить, сожмите новое вертикальное видео до 540×960 без звука и положите под теми же именами.

### Видео Регины и фото

В `js/config.js`:

```js
video: { src: "assets/video/regina.mp4", poster: "assets/img/regina-poster.webp" },
founderPhoto: "assets/img/regina.webp",
```

Видео вертикальное 9:16, MP4 (H.264), до 10 МБ. Оно загружается только после нажатия и не запускается само. Пока `src` пустой, показывается постер без кнопки запуска.

### Вопросы и ответы

Массив `faq` в `js/config.js`. В ответах можно писать `{creditWindow}`, `{creditedYearPrice}`, `{trialPrice}`, `{yearPrice}`, и на месте этих меток подставятся значения из настроек. Вопрос, в ответе которого есть `[ЗАПОЛНИТЬ`, на сайте скрыт.

### Ссылки в подвале и контакты

`links` в `js/config.js`: оферта, Telegram-канал, социальные сети, сайт Академии, почта, телефон. Пункты без ссылки скрываются.

## Яндекс Метрика

Укажите номер счётчика в `metrikaId`. Цели (reachGoal):

| Цель | Когда |
|---|---|
| `terms_view` | Блок условий попал в экран |
| `click_trial`, `click_year` | Нажатие кнопки пакета; параметр `block`: `hero`, `terms`, `final` |
| `sticky_click` | Нажатие закреплённой кнопки на телефоне |
| `video_start`, `video_complete` | Запуск и досмотр видео |
| `faq_open` | Раскрытие вопроса; параметр `question` |
| `scroll_25`, `scroll_50`, `scroll_75`, `scroll_100` | Глубина прокрутки |
| `scale_interact` | Нажатие на шкалу или карточку пакета |

## Живая сеть в первом экране

`js/network.js` загружается после загрузки страницы. На телефонах узлов вдвое меньше: 18 вместо 36. При включённом «уменьшении движения», в режиме экономии трафика и на слабых устройствах сеть не запускается, вместо неё показывается статичная картинка `assets/img/network-static.svg`.

## Локальный просмотр

```
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Если открыть файл двойным щелчком, страница не сработает: браузер не запускает модули и не читает JSON с диска.
