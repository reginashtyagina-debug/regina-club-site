# Деловой клуб Регины Штягиной — лендинг

Подстраница сайта Академии PR и Личного бренда (reginashtyagina.ru). Чистые HTML/CSS/JS, без сборки и зависимостей — достаточно открыть `index.html` в браузере.

## Визуальный стиль — по брендбуку SHTYAGINA 2026

«Яркая система» брендбука (Деловой клуб, соцсети): голубой `#8FD0E3`, красный `#FF1D3D`,
зелёный `#7FAE7D`, чёрный `#0B0B0B`, молочный `#F8F7F4`. Второстепенный текст —
графитовый `#6B6B6B`; серый `#A7A7A7` — только линии и декор. Кнопки — чёрный текст
на красном. Подписи — строчными, без Caps Lock. Все цвета — токены в начале `css/styles.css`.

**Логотип** — `images/brand/logo-black.png` (на светлом) и `logo-milk.png` (на тёмном),
взяты из брендбука. Только «shtyagina», иконку «S.» рядом не ставим. Иконка «S.»
используется как значок вкладки браузера (`favicon-64.png`). Логотип в брендбуке —
растровый; если есть векторный SVG, лучше заменить им.

**Шрифт** — Futura MediumC (заголовки, цифры) и Futura LightC (текст). Файлов шрифта
в брендбуке нет — он сам набран Jost, «открытым аналогом Futura». Положите файлы
Futura в папку `fonts/` (`FuturaMediumC.woff2`, `FuturaLightC.woff2`), до этого
страница показывается в Jost.

## Структура

```
index.html      — разметка всех блоков (1–8 + 4.5)
css/styles.css  — стили, mobile-first
js/data.js      — ДАННЫЕ: эксперты (EXPERTS) и отзывы (REVIEWS)
js/render.js    — выводит карточки из data.js (редактировать не нужно)
```

## Как заменить медиа

Все места под фото и видео помечены в коде комментариями:

| Что | Где искать |
| --- | --- |
| Приветственное видео | `index.html` → `<!-- ССЫЛКА НА ВИДЕО С GETCOURSE -->` |
| Фото с живой встречи | `index.html` → `<!-- ФОТО С ЖИВОЙ ВСТРЕЧИ КЛУБА -->` |
| Фото Регины | `index.html` → `<!-- ФОТО РЕГИНЫ -->` |
| Фото экспертов | `js/data.js` → поле `photo` в массиве `EXPERTS` |
| Скрины отзывов | `js/data.js` → поле `screenshot` в массиве `REVIEWS` |
| Фото офлайн-встречи (отзыв С. Можаевой) | `js/data.js` → поле `photo` в массиве `REVIEWS` |

Фото Регины лучше всего давать **вырезанным на прозрачном фоне** (PNG/WebP, по пояс) —
оно «врезается» в зелёный блок. Эксперты — обычный вертикальный портрет (от 800×1000),
он встаёт в правый нижний угол карточки. Фотогид брендбука: мягкий естественный свет,
тёплый взгляд, фон молочный или голубой.

## Счётчик участников

- `CLUB_STATS.members` в `js/data.js` — число участников в плашке на первом экране. `null` — плашка скрыта.

## Как добавить эксперта или отзыв

Откройте `js/data.js` и допишите объект в конец нужного массива — разметку трогать не нужно:

```js
{ role: 'Юрист', name: 'Имя Фамилия', niche: 'защита имени и контента', photo: 'images/experts/name.jpg' },
{ author: 'Имя Фамилия', text: 'Текст сообщения (для alt)', screenshot: 'images/reviews/name.png' },
```

## Скрины отзывов — как подготовить

- Обрезать по самому сообщению (облачку): без строки статуса телефона, шапки чата и поля ввода.
- Скрыть номера телефонов, @ники, аватары и сообщения посторонних людей.
- Одна тема оформления для всех скринов (лучше светлая) — лента будет выглядеть единообразно.
- Ширина исходника — от 800 px, формат PNG или WebP; класть в `images/reviews/`.
- Получить согласие автора на публикацию его сообщения.
