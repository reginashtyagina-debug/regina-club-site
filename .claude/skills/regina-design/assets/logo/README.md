# Логотип

| Файл | Что это |
|---|---|
| `shtyagina-black.png` | Чёрный вордмарк для светлого фона, прозрачный фон |
| `shtyagina-white.png` | Белый вордмарк для тёмного фона, прозрачный фон |

Оба файла вырезаны 1 октября 2026 года из слайда карусели (1080×1350). Логотип в них 168×36 px, плюс 4 px прозрачного поля. Белая версия — та же форма, перекрашенная в белый. Логотип не перерисовывался.

Этого размера хватает для шапки сайта и слайдов 1080 px, где логотип стоит малым размером. Для печати, PDF, книги и крупных макетов нужен исходник:

- `shtyagina-black.svg`, `shtyagina-white.svg` — вектор от дизайнера;
- или PNG шириной от 1200 px с прозрачным фоном.

Когда исходник появится, положите его сюда под этими именами и замените PNG на сайте (`assets/logo/` и `js/config.js`).

Логотип не перерисовывать, только оригинальные файлы.
