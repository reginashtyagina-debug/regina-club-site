# Regina Design

Единый визуальный стандарт Академии PR и Личного бренда Регины Штягиной.
Таглайн: «Превратите репутацию в доход». Палитра-слоган: «Яркий интеллект. Стратегия. Результат.»

## Как работать

1. Прочитай этот файл целиком.
2. Возьми цвета и размеры из `tokens.css`. Не придумывай оттенки.
3. Логотип и фото бери только из `assets/`. Не перерисовывай логотип.
4. Определи уровень продукта (раздел 2) и выбери интенсивность палитры.
5. Для сайтов и лендингов прочитай раздел 10.
6. После сборки пройди чек-лист (раздел 8).

## 1. Позиционирование визуала

- Архетип «Правитель» в формулировке «власть в бархатной перчатке»: мягко, тепло, уверенно.
- Мягкость задают фото, жесты, свет и текст. Палитра остаётся яркой и чёткой.
- Ориентир по тону — премиальные бизнес-клубы. Не инфобизнес.
- Только русский язык в названиях продуктов и подписях.

## 2. Две интенсивности

| Уровень | Где | Стиль |
|---|---|---|
| Флагман | «От Анонима до Звезды» (250 000 ₽), Годовое сопровождение (660 000 ₽) | Академичный: чёрный, белый, один сдержанный акцент |
| Клуб и соцсети | Деловой клуб, Reels, Stories, карусели | Полная палитра: голубой, красный, зелёный |
| Сайт Делового клуба | Лендинг клуба | Графит, тёплый белый, теннисный лайм (решение Регины, раздел 10) |

Один бренд, разная интенсивность. Не два разных бренда.

## 3. Палитра

| Роль | Цвет | HEX |
|---|---|---|
| Основной | Голубой | #8FD0E3 |
| Акцент, CTA | Красный | #FF1D3D |
| Вторичный | Зелёный | #7FAE7D |
| Текст, основа | Чёрный | #0B0B0B |
| Фон | Молочный | #F8F7F4 |
| Вторичный текст | Серый | #A7A7A7 |
| Личный код (~5% контента) | Теннисный лайм | #D7FF00 |

HEX лайма взят из стандарта рилсов Регины (навык regina-reels-editor: «tennis-ball yellow-green #D7FF00»).

Правила:
- Голубой и зелёный — фоны и блоки.
- Чёрный — плашки цитат и выводов.
- Молочный — светлые слайды и страницы.
- Красный — только числа и ключевые слова.
- Инфографика: положительные значения зелёным, отрицательные чёрным.
- Чёрные перья из старого брендбука не используем. Вместо них — теннисные линии корта.
- Лайм никогда не ставится текстом на светлый фон: контраст около 1,1:1, текст не читается. На светлом фоне лайм — только заливка с чёрным текстом или маленькая метка с чёрным контуром.
- Серый #A7A7A7 на молочном фоне даёт контраст 2,2:1. Для мелкого текста на сайте он не проходит требования доступности, там вторичный текст темнее (раздел 10).

## 4. Типографика

- Заголовки: Montserrat Black, капс.
- Подзаголовки и цитаты: PT Serif Italic.
- Основной текст: чистый гротеск (Montserrat Regular или Medium).
- Допустимо сочетать жирный дисплейный и чистый гротеск по задаче.
- Все шрифты с кириллицей. Файлы лежат в `assets/fonts/` в формате woff2, отдельно кириллица и латиница. Лицензия SIL Open Font License, тексты лицензий там же.

| Файл | Начертание |
|---|---|
| `montserrat-*-400-normal.woff2` | Montserrat Regular |
| `montserrat-*-500-normal.woff2` | Montserrat Medium |
| `montserrat-*-600-normal.woff2` | Montserrat SemiBold (субтитры рилсов, заголовки сайта клуба) |
| `montserrat-*-900-normal.woff2` | Montserrat Black (заголовки макетов) |
| `pt-serif-*-400-italic.woff2` | PT Serif Italic |
| `pt-serif-*-400-normal.woff2`, `pt-serif-*-700-normal.woff2` | PT Serif Regular и Bold |

Открытый вопрос: в референсе карточек упомянут Futura. Нужно решить, оставляем Montserrat как основной или добавляем Futura.

## 5. Логотип

- Файл: жирный строчный вордмарк «shtyagina» → `assets/logo/`.
- Хедер на каждом слайде и странице: логотип малым размером слева сверху, «Академия PR и Личного бренда» малым капсом справа сверху, тонкая чёрная линия под ними.
- Свободное поле вокруг логотипа не меньше высоты буквы «t».
- Не растягивать, не менять цвет, не добавлять тени.
- Версии на тёмном и цветном фоне: нужны (см. «Что нужно собрать»).

Имена файлов, которые ждут сайт и шаблоны:

| Файл | Где |
|---|---|
| `assets/logo/shtyagina-black.svg` | Светлый фон |
| `assets/logo/shtyagina-white.svg` | Тёмный фон |
| `assets/logo/shtyagina-black.png`, `shtyagina-white.png` | Макеты, где SVG не подходит; ширина не меньше 1200 px, прозрачный фон |

Пока файлов нет, логотип не рисовать заново: на сайте на его месте временно стоит набранное шрифтом слово «shtyagina» (раздел 10).

## 6. Композиция

Базовый шаблон — карточка из recap-эфира клуба:
- крупный блок одного цвета, жирный заголовок поверх;
- фото человека встроено в композицию, а не лежит рядом с текстом;
- цитата на чёрной плашке с маленькой голубой подписью капсом;
- числа и результаты крупно в рамке, подпись мелко под ними;
- вывод — блок «Главное» с цветной полосой слева;
- ритм: цветной слайд, светлый, чёрная плашка;
- один слайд — одна мысль;
- финал: чёрный фон, «Превратите репутацию в доход», одно действие.

Фото:
- портрет Регины, где уместно, вырезается по контуру, текст обтекает его;
- должно выглядеть органично и работать на смысл;
- тёплое, живое выражение. Строгий недосмеянный бизнес-образ не подходит.

## 7. Текст на макетах

- Короткие фактические фразы. Цифры вместо давления на боль.
- Без «Знакомо?», без «Не курс. Не марафон», без перечёркнутых цен.
- Убирать описательно-эмоциональные связки.
- Без английских терминов: «видимость в ответах ИИ», не GEO.
- В клубе «участников», не «участниц».

## 8. Чек-лист проверки

- [ ] Цвета только из палитры, HEX совпадают
- [ ] Красный только на числах и ключевых словах
- [ ] Логотип из файла, хедер по стандарту
- [ ] Шрифты Montserrat и PT Serif, кириллица отображается
- [ ] Один слайд — одна мысль
- [ ] Чёрные перья не использованы
- [ ] Лайм не больше ~5%
- [ ] Лайм не стоит текстом на светлом фоне
- [ ] Интенсивность палитры соответствует уровню продукта
- [ ] Нет инфобизнес-оборотов и английских слов
- [ ] Фото встроено в композицию

Дополнительно для сайтов:
- [ ] Контраст текста не ниже 4,5:1, у значков и линий шкал не ниже 3:1
- [ ] Шрифты подключены локально из woff2, с `font-display: swap`
- [ ] Страница проверена на ширине 360, 768 и 1440 px

## 9. Что нужно собрать в assets/

Папки созданы, в каждой лежит `README.md` с тем, что туда положить.

- logo/: вордмарк в PNG и SVG, версии для светлого и тёмного фона — **пока нет**
- photos/: белый костюм (editorial), чёрно-белый диптих, вырезанные по контуру PNG — **пока нет**
- fonts/: Montserrat, PT Serif (при необходимости Futura) — **есть**, кроме Futura
- templates/: PDF recap-эфира клуба, пилотная карусель «Клиент открыл ChatGPT» — **пока нет**
- references/: референсы плотности и раскладки (только структура, без копирования чужих цветов) — **пока нет**

## 10. Сайт Делового клуба: принятые решения

Решения приняты Региной 1 октября 2026 года при сборке лендинга клуба (репозиторий `regina-club-site`). Для других сайтов Академии они не обязательны.

**Цвета.** Регина оставила акценты, которые утвердила на макете сайта, вместо полной палитры клуба из раздела 2:

| Роль | HEX |
|---|---|
| Графит: первый экран, финал, основной текст | #161616 |
| Тёплый белый: фон | #F3F1EE |
| Белый: карточки | #FFFFFF |
| Вторичный текст на светлом | #6B6864 (контраст 4,9:1) |
| Вторичный текст на тёмном | #A9A6A1 (контраст 7,5:1) |
| Линии | #DAD6D0 |
| Лайм: связи сети, главная кнопка на тёмном, метка на шкале | #D7FF00 |

Голубой, красный и зелёный на сайте клуба пока не используются.

**Шрифты на сайте.** Заголовки Montserrat SemiBold строчными с плотным трекингом, а не Montserrat Black капсом: так в брифе лендинга и в субтитрах рилсов. Подзаголовок первого экрана и вводные абзацы — PT Serif Italic, как в разделе 4. Основной текст — Golos Text по брифу лендинга, а не Montserrat.

**Хедер на сайте** по разделу 5: логотип слева, «Академия PR и Личного бренда» малым капсом справа, тонкая линия под ними. На тёмном первом экране линия и подпись светлые.

**Финал** по разделу 6: тёмный фон и таглайн «Превратите репутацию в доход». Кнопок в финале две, тест-драйв и год, потому что так требует бриф лендинга.

**Блок «Главное»** с лаймовой полосой слева — для условия зачёта в блоке «Условия участия».

**Логотип.** Пока нет файла из `assets/logo/`, на сайте стоит набранное слово «shtyagina» (Montserrat Black, строчные). Как только файл появится, его нужно подключить в `js/config.js` проекта сайта, поле `logo`, а набранное слово уйдёт само.
