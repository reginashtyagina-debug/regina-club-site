# Дизайн-план лендинга клуба

## Основа

Фирменный стиль Регины (из её стандартов для рилсов и каруселей): editorial, премиальное деловое медиа уровня Forbes и HBR, fashion-журнал, Pinterest-минимализм. Базовая палитра: чёрный, тёплый белый, графит, серый. Теннисный лайм — только редкий акцент. Шрифт для заголовков — Montserrat SemiBold, как в субтитрах рилсов.

Фирменная палитра заменяет стартовое предложение брифа (хвойный зелёный `#12332E` и лайм `#CFE63A`). Бриф сам говорит, что палитра бренда приоритетнее.

## Цвета

| Токен | Цвет | Роль |
|---|---|---|
| `--graphite` | `#161616` | Первый экран, финальный блок, основной текст |
| `--warm-white` | `#F3F1EE` | Фон страницы, текст на тёмном |
| `--white` | `#FFFFFF` | Поверхности: карточки пакетов, поля |
| `--grey` | `#6B6864` | Второстепенный текст на светлом (контраст 5,0:1) |
| `--line` | `#DAD6D0` | Линии и разделители |
| `--lime` | `#D7FF00` | Единственный акцент: связи сети, кнопка на тёмном, отметка на шкале |

Лайм никогда не стоит текстом на светлом фоне. На светлом он работает только как заливка кнопки с графитовым текстом или как метка на шкале.

## Шрифты

- **Montserrat SemiBold 600**: заголовки, крупно, трекинг −0,02…−0,035em.
- **Golos Text 400/500**: основной текст, кнопки, подписи.
- Оба шрифта подключены локально в формате woff2, отдельно кириллица и латиница. Первый экран использует только кириллицу.

## Раскладка

Журнальная асимметрия: на компьютере узкая левая колонка для заголовка раздела и широкая правая для содержания. На телефоне всё идёт одной колонкой. Выравнивание по левому краю, без центровки.

```
ПЕРВЫЙ ЭКРАН (графит, живая сеть на всю площадь)
┌───────────────────────────────────────────────┐
│  ·  ·—·    ·        ·—·   ·        ·──·        │
│                                    ┌────────┐ │
│  Деловой клуб                       │ видео  │ │
│  Регины Штягиной                    │  9:16  │ │
│  подзаголовок                       │ постер │ │
│  оффер                              └────────┘ │
│  [Главная кнопка]  [Вторая кнопка]             │
└───────────────────────────────────────────────┘

РАЗДЕЛ (светлый)
┌──────────────┬────────────────────────────────┐
│ Заголовок    │ строка ─────────────────────── │
│ раздела      │ строка ─────────────────────── │
│              │ строка ─────────────────────── │
└──────────────┴────────────────────────────────┘

УСЛОВИЯ
┌──────────────────────┬──────────────────────┐
│ Тест-драйв           │ Год в клубе          │
│ 5 490 ₽, 30 дней     │ 54 900 ₽, 12 месяцев │
│ [Начать тест-драйв]  │ [Вступить на год]    │
└──────────────────────┴──────────────────────┘
 Шкала: [30 дней][7][────── 12 месяцев ──────]
```

Видео в первом экране вертикальное (9:16), в формате рилсов Регины. Аудитория узнаёт этот формат по Instagram.

## Принципы

1. Смелость только в одном месте: живая сеть в первом экране. Всё ниже спокойное и светлое.
2. Движение только в ответ на действие человека: шкала пакетов, раскрытие вопросов. Никаких появлений блоков при прокрутке и эффектов при наведении на карточки.
3. Структура несёт смысл: нумерация недель только в блоке «Первые 30 дней», потому что там последовательность.
4. Прямые факты и цифры крупно, без декора.

## Сверка с брифом и что изменено

- **Палитра.** Хвойный зелёный заменён на фирменный графит, лайм `#CFE63A` на фирменный `#D7FF00`. Причина: просьба Регины использовать фирменный стиль.
- **«Что внутри клуба».** Сетку одинаковых карточек с иконками заменила журнальным списком с линиями. Сетка карточек выглядит как шаблон для любого лендинга.
- **Подписи над заголовками.** Отказалась от маленьких подписей капсом над каждым заголовком («О КЛУБЕ», «ФОРМАТЫ»): это шаблонный приём из запретного списка.
- **Шапка с меню.** Убрала. Страница одна и ведёт к одному действию, меню отвлекает. Первый экран сам называет клуб.
- **Значок «Рекомендуем» на выделенном пакете.** Убрала. По брифу выделение — только оформление, содержимое карточек одинаковое.
- **Тёмные блоки.** Тёмных только два: первый экран и финальный призыв. Это обрамление страницы, а не «тёмный фон со вспышками лайма на всех блоках».

## Какие навыки применены

**Фирменный стиль Регины** (навыки Regina Carousel и Regina Reels Editor):
- editorial, асимметрия, крупная типографика, много воздуха, никакого визуального шума;
- графитовый, тёплый белый и серый как основа, лайм `#D7FF00` только как редкий акцент;
- Montserrat SemiBold для заголовков;
- вертикальное видео 9:16, как в рилсах.

Холодный красный из фирменной палитры пока не используется: в навыках нет его точного кода. Пришлите код цвета, если он нужен на странице.

**UI/UX Pro Max.** Общий подбор навыка предложил фиолетовую палитру, яркий блочный стиль и появление блоков при прокрутке. Это расходится с фирменным стилем и брифом, поэтому не взято. Применены его правила:
- контраст текста не ниже 4,5:1, у шкалы и значков не ниже 3:1;
- видимый фокус, ссылка «Перейти к содержанию»;
- закреплённая кнопка на телефоне не закрывает фокус (`scroll-padding-bottom`);
- шкала рисуется через `transform`, а не через ширину, и перезапускается при каждом нажатии;
- у прокрутки отзывов есть кнопки «назад» и «вперёд», чтобы листать без свайпа;
- кнопки не меньше 44 px по высоте, `touch-action: manipulation`, цены с моноширинными цифрами;
- отложенная загрузка сети, видео и изображений, шрифты с `font-display: swap`.

## Фирменный стандарт regina-design

Навык лежит в `.claude/skills/regina-design`. Цвета сайта Регина оставила прежние: графит, тёплый белый, лайм. Полная палитра клуба из навыка (голубой, красный, зелёный) на сайте пока не используется. Из навыка на сайт перенесено:
- шапка по стандарту: логотип слева, «Академия PR и Личного бренда» малым капсом справа, тонкая линия под ними (в первом экране и на странице политики);
- PT Serif Italic для подзаголовка первого экрана, текста «Ступени системы» и подписи в финале;
- блок «Главное» с лаймовой полосой слева для условия зачёта;
- финал с таглайном «Превратите репутацию в доход».

Логотип подключается из `assets/logo/shtyagina-white.svg` (тёмный фон) и `shtyagina-black.svg` (светлый). Пока файлов нет, на его месте временно стоит набранное слово «shtyagina».
